# 폼·다이얼로그 여백 전수 점검 설계

- 작성일: 2026-08-11
- 상태: 사용자 승인 완료
- 범위: 웹 전체의 폼 필드, 다이얼로그 본문, 하단 액션 영역과 모바일 레이아웃

## 목표

화면별 임시 margin 대신 공통 레이아웃 규칙으로 필드와 액션의 시각적 구분을
보장한다.

## 규칙

- 단일 필드가 연속되는 다이얼로그 본문은 16px 간격으로 쌓는다.
- 제목·본문, 본문·하단 액션은 각각 최소 24px로 분리한다.
- 액션 버튼은 `er-dialog-actions` 또는 `er-action-row`로 묶고 버튼 사이에는
  12px 간격을 둔다.
- `ParticipantEditDialog`처럼 기존 공통 폼 클래스를 쓰지 않는 모달은
  `er-dialog-form`을 사용하도록 바꾼다.
- 좁은 화면에서는 필드와 액션을 세로로 쌓되 동일한 간격 규칙을 유지한다.

## 검증

- 모든 Dialog 사용처와 인라인 form/action 행을 정적 검색해 공통 클래스 누락을
  확인한다.
- 핵심 다이얼로그 컴포넌트 테스트가 공통 form/action 클래스를 검증한다.
- web 타입 검사·테스트·production build를 실행한다.
