# 참가 명단 정렬 우선순위 및 열 순서 개선 설계

## 목표

참가 명단 헤더의 다중 정렬 우선순위를 기존 원형 숫자 배지보다 덜 도드라지고 자연스럽게 표시한다. 동시에 `등록 시점` 열을 표의 맨 마지막으로 이동해 주요 참가자 정보와 작업 영역을 먼저 읽을 수 있게 한다.

## 정렬 우선순위 표시

- 이름, 조직, 학년 헤더의 기존 정렬 아이콘과 클릭 동작은 유지한다.
- 활성 정렬 기준은 아이콘 바로 뒤에 작은 위첨자 숫자로 우선순위를 표시한다. 예: `↕¹`, `↕²`, `↕³`.
- 위첨자 숫자는 별도의 배경이나 테두리를 사용하지 않고 강조색 텍스트로만 표현해 헤더를 과도하게 강조하지 않는다.
- 비활성 정렬 기준에는 우선순위 숫자를 표시하지 않는다.
- 접근 가능한 이름에는 기존처럼 실제 우선순위를 포함해 시각적 표현에 의존하지 않는다.

## 열 순서

- 헤더와 각 명단 행에서 `등록 시점`을 `작업` 뒤의 마지막 열로 이동한다.
- 최종 순서는 `이름 → 조직 → 참가자 구분 → 학년 → 성별 → 상태 → 작업 → 등록 시점`이다.
- 열의 데이터, 상태 필터, 작업 버튼 동작은 변경하지 않는다.

## 반응형 및 접근성

- 위첨자는 아이콘과 한 덩어리로 정렬되도록 배치하고 헤더 높이를 늘리지 않는다.
- 좁은 화면의 기존 가로 스크롤 동작을 유지한다.
- 정렬 버튼의 `aria-pressed`와 우선순위를 포함한 접근 가능한 이름을 유지한다.

## 검증

- 기본 정렬에서 조직, 학년, 이름에 각각 `1`, `2`, `3`의 위첨자 우선순위가 표시되는지 확인한다.
- 정렬 기준을 끄거나 다시 켰을 때 위첨자 번호가 현재 활성 기준에 맞게 다시 계산되는지 확인한다.
- 원형 숫자 배지 스타일이 제거되고 위첨자 텍스트 스타일이 적용되는지 확인한다.
- `등록 시점` 헤더와 각 행의 값이 `작업` 뒤 마지막 열에 표시되는지 확인한다.
- 기존 정렬, 필터, 작업 버튼 기능이 그대로 동작하는지 회귀 검증한다.
