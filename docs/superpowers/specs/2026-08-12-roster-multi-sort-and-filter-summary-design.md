# 참가 명단 다중 정렬 및 필터 요약 설계

## 목표

참가 명단에서 조직, 학년, 이름을 동시에 정렬하되 현재 적용 중인 정렬 기준과 우선순위를 사용자가 바로 알 수 있게 한다. 검색과 헤더 필터의 적용 상태도 명단 상단에 요약하고, 각 조건을 개별적으로 해제할 수 있게 한다.

## 다중 정렬

- 정렬 가능한 기준은 조직, 학년, 이름 세 가지다.
- 최초 활성 기준과 고정 우선순위는 `조직 → 학년 → 이름`이다.
- 각 헤더의 정렬 아이콘을 누르면 해당 기준만 활성화하거나 비활성화한다.
- 비활성 기준을 다시 켜면 클릭 순서가 아니라 원래의 고정 우선순위 위치로 돌아간다.
- 활성 기준만 순서대로 비교한다. 활성 기준이 모두 같으면 입력된 명단 순서를 보존한다.
- 세 기준을 모두 끄면 입력된 명단 순서를 그대로 표시한다.
- 활성 정렬 아이콘은 강조색으로 표시하고, 현재 활성 기준 사이의 우선순위를 `1`, `2`, `3`으로 보여준다. 중간 기준이 꺼지면 남은 기준의 표시 번호는 연속되게 다시 계산한다.

예를 들어 학년을 끄면 조직은 `1`, 이름은 `2`로 표시되고 정렬도 조직 다음 이름 순서로 적용된다.

## 필터 요약

- 검색창 위에 현재 적용 중인 검색 및 필터 조건을 작은 배지 목록으로 표시한다.
- 전체 값을 선택한 필터는 적용 중인 조건이 아니므로 표시하지 않는다.
- 표시 형식은 `[필터명: 값 ×]`이다. 예: `성별: 남성 ×`, `조직: 삼개사 ×`, `검색: 홍길동 ×`.
- 배지의 제거 버튼을 누르면 해당 조건만 기본값으로 되돌리고 명단을 즉시 다시 계산한다.
- 활성 조건이 하나도 없으면 요약 영역을 렌더링하지 않는다.
- 헤더 필터 아이콘은 해당 필터가 적용 중일 때 강조색을 유지한다. 메뉴가 열려 있는 상태와 값이 적용된 상태는 각각 접근성 속성과 시각 스타일로 구분한다.

## 상태 및 데이터 흐름

- 단일 `sortKeys` 상태가 활성화된 정렬 기준을 고정 우선순위 순으로 보관한다.
- 정렬 아이콘은 기준을 상태에 추가하거나 제거하고, 비교 함수는 `sortKeys`를 앞에서부터 순회한다.
- 기존 검색 및 필터 상태에서 표시용 배지 목록을 파생한다. 별도의 중복 상태를 만들지 않는다.
- 배지 제거는 해당 검색 또는 필터 상태를 기존 기본값인 빈 문자열 또는 `ALL`로 변경한다.

## 접근성 및 화면 동작

- 정렬 버튼의 `aria-pressed`로 활성 여부를 전달한다.
- 정렬 버튼의 접근 가능한 이름에 현재 우선순위를 포함한다.
- 필터 배지 제거 버튼은 `성별 필터 해제`처럼 구체적인 접근 가능한 이름을 사용한다.
- 좁은 화면에서는 필터 배지가 다음 줄로 자연스럽게 줄바꿈된다.

## 검증

- 최초 렌더링에서 조직, 학년, 이름 순으로 정렬되는지 검증한다.
- 각 기준을 끄고 다시 켰을 때 남은 기준과 고정 우선순위가 올바르게 적용되는지 검증한다.
- 활성 정렬 아이콘의 상태와 표시 번호를 검증한다.
- 검색 및 필터 선택 시 올바른 요약 배지가 표시되는지 검증한다.
- 각 배지 제거 시 해당 조건만 해제되고 다른 조건은 유지되는지 검증한다.
- 기존 필터 팝오버, 바깥 클릭, Escape 닫기 동작이 유지되는지 회귀 검증한다.
